# GrowDay - Self Growth App

GrowDay is a lightweight web application designed to help you build yourself, one day at a time. It features habit tracking, daily goal setting, and a clean interface that can be installed on both mobile and desktop devices.

## 🚀 Live Demo
You can try the live application here:
[https://sreedevig124.github.io/growday/](https://sreedevig124.github.io/growday/)

## 📱 Features
* Installable Progressive Web App (PWA) functionality
* Clean, responsive UI for mobile and desktop
* Light/Dark theme toggling
* Daily progress reset option

## 🛠️ Built With
* HTML5
* CSS3
* JavaScript (ES6)
* Web App Manifest
